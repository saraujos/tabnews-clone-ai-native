# tabnews-clone-ai-native
Clone do TabNews desenvolvido com uma abordagem AI-Native durante o curso.dev/ia, de Filipe Deschamps.

## Desenvolvimento

Requer Node.js 20.9 ou superior e npm.

```sh
npm ci
npm run dev
```

Acesse http://localhost:3000 para visualizar a página inicial.

O projeto utiliza Next.js 16.2.12, React 19.2 e JavaScript com App Router.
A página inicial fica em `app/page.js` e o layout em `app/layout.js`.

## Produção

```sh
npm run build
npm start
```
